# EasyPhotoEditer
*画像編集を、より簡単に。*

## このソフトについて
Windows上で動作し、簡単に使える画像編集ソフトです。<br>以下の公式サイトまたはReleasesからダウンロードできます。<br>https://shizukimobile.github.io/EasyPhotoEditer/

### 編集機能
ベースの画像に、以下のような編集をすることができます。
- 図形を入れる
  - 挿入可能な図形:丸(円)、四角形、角丸四角形、チェックマーク
- 文字を入れる
- 別の画像を合成する(合成する画像を、角丸四角形や円形に切り抜くこともできます)

### 便利な使い方のヒント
- 編集したい画像は、画面にドラッグ＆ドロップするだけで読み込めます。
- 「ファイル」→「オプション」から「画像をドラッグ&ドロップしたときの動作」を「画像を編集中の画像に合成する」にすれば、合成する画像もドラッグ&ドロップで読み込めます。
- 合成した画像を右クリックして「図形に合わせてトリミング」を選ぶと、円形や角丸四角形にくり抜けます。
- 文字や図形を選択した状態でキーボードの「矢印キー」を押すと、1ピクセル単位で位置を微調整できます。
- 万が一ソフトが強制終了しても、次回起動時に作業内容を自動復元するバックアップ機能を備えています。

## 動作環境
Windows 10以降が必要です。32bit版のWindowsでは動作しません。<br>
別途ランタイム等を導入する必要はありません。

## 注意事項
- 起動時に、Microsoft Defender SmartScreenによる警告メッセージが表示されることがあります。<br>これはWindowsの仕様であり、ソフトが危険であることを示すものではありません。<br>警告が表示された場合は、「詳細情報」→「実行」の順にクリックするとソフトを起動することができます。
- 「スマート アプリ コントロール」 の設定が有効な場合、ソフトの起動がブロックされることがあります。<br>その場合はスマート アプリ コントロールを無効にして再度起動をお試しください。

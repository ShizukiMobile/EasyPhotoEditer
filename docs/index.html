EasyPhotoEditer は、テキスト追加・図形描画・別画像の合成やトリミングを直感的に行える Windows 向けの軽量画像エディタです。ダークテーマの落ち着いた UI と万が一の異常終了時に備えたバックアップ復元機能で、 日々のスクリーンショット加工や資料作成はもちろん、SNS 用の自己紹介カードやプロフィールカードの制作にも幅広く活用できます。

FEATURES

必要な機能を、迷わない操作性で

高機能すぎるペイントソフトは不要な場面に最適化。画像を開いて数秒で注釈や図形を追加し、すぐに保存できます。

豊富な図形・テキスト注釈

テキストボックス、丸（円）、四角形、角丸四角形、チェックマークをワンクリックで配置。 フォント・文字サイズ・文字色・枠線の色や太さまで細かく調整できます。

画像の挿入＆図形トリミング

編集中の画像の上に別の画像やアイコンを重ねて配置可能。 挿入した画像は「丸」や「角丸四角形」にワンタッチでトリミングでき、重ね順変更や複製にも対応。 自己紹介カードやプロフィールカードの制作にも最適です。

快適な編集ワークフロー

画像のドラッグ＆ドロップ読み込み、元に戻す / やり直す、柔軟なズーム操作やウィンドウフィット表示に対応。 オプション画面でよく使う既定のスタイルを保存し、次回から同じ設定で素早く描画できます。

自動バックアップ＆安心のリカバリ機能

編集中の作業内容を元画像とは別に随時バックグラウンドで一時バックアップ。 万が一アプリが予期せず終了した場合でも、次回起動時の復元ダイアログから編集状態をそのまま復元できます。

HOW TO USE

3ステップですぐに編集スタート

インストーラーや面倒な初期設定は一切不要。ダウンロードして解凍すればすぐに使えます。

01

ダウンロードして展開

EasyPhotoEditer_v1.0.0.zip をダウンロードし、任意のフォルダへ展開します。

02

アプリを起動して画像をドロップ

EasyPhotoEditer.exe を起動し、編集したい画像ファイルをウィンドウへドラッグ＆ドロップ（または Ctrl+O）します。

03

注釈を入れて保存

ツールバーや右クリックメニューからテキストや図形・画像を配置し、Ctrl+S で編集後の画像を書き出して完了です。

SHORTCUTS

主なショートカットキー

キーボード操作を組み合わせることで、さらにスピーディーに編集できます。

操作 ショートカット
画像を開く Ctrl + O
編集した画像を保存 Ctrl + S
元に戻す / やり直す Ctrl + Z / Ctrl + Y
選択中の要素を複製 Ctrl + D
選択中の要素を削除 Delete
ズームイン / アウト / 100%に戻す Ctrl + + / - / 0
